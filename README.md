# Student Management System

A full-stack Student Management System built using React and FastAPI.

## 🚀 Technologies Used

### Frontend
- React
- JavaScript
- HTML
- CSS
- Vite

### Backend
- Python
- FastAPI
- SQLAlchemy

### Database
- MySQL

## ✨ Features

- Add Student
- View Students
- Update Student
- Delete Student
- Search Student
- Student Management Dashboard
- REST API using FastAPI
- MySQL database integration
